# analise_desempenho_academico

Este conjunto de dados contém informações sobre 1000 estudantes, incluindo hábitos de estudo (horas estudadas, frequência), fatores de estilo de vida (sono, atividades extracurriculares, trabalho de meio período), dados demográficos (gênero, escolaridade dos pais) e resultados acadêmicos (nota final e classificação). É ideal para análise exploratória de dados, regressão e classificação, permitindo prever o desempenho dos alunos com base em fatores comportamentais e demográficos.
Casos de uso: previsão de notas em provas, classificação de notas, análise exploratória de dados sobre fatores de desempenho acadêmico, análise de importância de variáveis.

-fatores como trabalho/ sono, interfere no resultado geral?

-quantos trabalham e estudam?

-quantos só estudam?

-escolaridade dos pais interefere na motivação final (nos que tiram melhores notas)?

-genero interfere?

-escolaridade dos pais tem ligação com os alunos mais dedicados?

-quem trabalha e estuda tira nota pior ou melhor?
